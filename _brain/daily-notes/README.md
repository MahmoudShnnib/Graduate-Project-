# Daily Notes

Chronological working log of what happened each session — what was built, what broke, what decisions were made, and what's next. One file per day named `YYYY-MM-DD-title.md` (e.g. `2026-04-17-enrollment-refactor.md`).

Use these to recover session context quickly: link out with [[wikilinks]] to any [[decisions]], [[bugs-and-fixes]], or [[research]] notes created that day. Tag entries with `#daily` plus topic tags like `#filament`, `#enrollment`, `#grades`.
