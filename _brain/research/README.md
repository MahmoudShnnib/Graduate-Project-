# Research

Notes from exploring options, reading docs, comparing approaches, or investigating how something works before committing to an implementation. Captures the reasoning that usually evaporates once a [[decisions|decision]] is made.

File names use `YYYY-MM-DD-topic.md`. Link outward to the [[decisions]] that resulted, and tag with `#research` plus the topic (e.g. `#filament`, `#livewire`, `#pest`).
